# Amazonian rainforest bioaerosol influenced by African dust intrusion

R-code used for ASV generation from raw reads and further processing and analysis for the manuscript entitled "Amazonian rainforest bioaerosol influenced by African dust intrusion"

DADA2_16S.R and DADA2_ITS.R were used for processing raw reads into ASVs

Analysis_16S_reads.R and Analysis_ITS_reads.T were used for further processing and analysis of ASVs

Dataset S1.xlsx to Dataset S9.xlsx are additional datasets from the manuscript

Endotoxin_concentrations.xlsx is the output of the endotoxin LAL assay

IC_results is the data of the water soluble ion concentrations

FigureS1_Meteorology_and_Aerosol_data.xlsx is the data used for plotting Figure S1 from the manuscript

Figure_1.xlsx to Figure_4.xlsx is the data used for plotting Figure 1-4 from the main manuscript

SupplementaryDataFigureS1.xlsx contains the meteorological and aerosol datasets 

SupplementaryDataTaxonomy.xlsx contains the taxonomic composition from Phylum to Genus level for Bacteria and Fungi used for all analysis
